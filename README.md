# 🌸 Floresta das Fadas Rosa

Um jogo de plataforma retrô em **Pixel Art (16-bit)** com estética rosa pastel, inspirado nos clássicos estilo Super Mario.

## 🎮 Como Jogar
- **Mover:** `Setas (⬅️ / ➡️)` ou `A / D`
- **Pular:** `Seta para cima (⬆️)`, `W` ou `Espaço`
- **Objetivo:** Atravesse as 3 fases da floresta encantada, pule sobre as fadas para espantá-las (`+100 pts`), colete morangos e estrelas e alcance a **Árvore de Cristal**.

## 🚀 Como rodar localmente ou no GitHub Pages
1. Faça o upload dos arquivos `index.html`, `style.css` e `game.js` para um repositório no GitHub.
2. Vá em **Settings > Pages**, selecione a branch `main` e clique em **Save**.
